# Landing Page - Almacenes SIMAN El Salvador

Proyecto de sitio web responsivo de 3 páginas desarrollado para **Almacenes SIMAN El Salvador**
---

## 📌 Páginas del Sitio

1. **Inicio (`index.html`):** Presentación principal de la marca, banners promocionales y video informativo.
2. **Promociones (`promociones.html`):** Catálogo con ofertas exclusivas en tecnología, moda, hogar y beneficios Credisiman.
3. **Contacto (`contacto.html`):** Formulario de contacto interactivo y selector de sucursales en El Salvador.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica para las 3 páginas web.
- **CSS3:** Estilos personalizados, Flexbox y Grid Layout para diseño 100% responsivo.
- **Google Fonts:** Tipografías *Montserrat* y *Open Sans*.
- **Git & GitHub:** Control de versiones y publicación del repositorio.

---

---

## 🚀 Cómo Visualizar el Proyecto

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador web o ejecútalo con **Live Server** en Visual Studio Code.
